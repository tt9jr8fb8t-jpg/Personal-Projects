Reading the way it should feel

Calculus I — Limits & Continuity

The formal definition of a limit states that:

lim x→a f(x) = L

if for every ε > 0 there exists a δ > 0 such that whenever |x − a| < δ it follows that |f(x) − L| < ε.

Markdown Notebooks

Notes that keep up with your thinking

Write in Markdown and see it rendered live — headers, lists, bold, italics, and code blocks all formatted as you type. Add LaTeX equations for math and science, and attach notebooks right next to any book in your library.

  • Full Markdown with live preview — no mode switching
  • Mathematical equations rendered beautifully with KaTeX
  • Code blocks with syntax highlighting for any language
  • Stays right next to your reading — no app switching

Sketchbook

Think visually on an infinite canvas

Sometimes ideas need space. Gnos includes a full Excalidraw whiteboard so you can sketch diagrams, draw concept maps, or annotate ideas — all without leaving your reading environment.

  • Activity heatmap for the last 12 weeks
  • Reading streak to motivate a daily habit
